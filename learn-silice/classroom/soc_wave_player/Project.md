# Projet SOC Wave Player Gaëtan BOUZÉLOC

## Compilation

Pour compiler le projet et le charger sur la carte, utilisez la commande suivante :

```bash
make final FIRMWARE=step5_audio_stream
```

## Fonctionnalités

Le projet intègre les fonctionnalités suivantes :

- **Jeu de réflexe** : Un mini-jeu pour tester ses réflexes est inclus.
- **Contrôle audio avancé** : Il est possible d'accélérer, de ralentir et de reculer dans la musique.
- **Interface couleur** : L'interface graphique utilise la couleur.
- **Animation des LEDs** : L'affichage des LEDs change dynamiquement en fonction de la vitesse de lecture.
